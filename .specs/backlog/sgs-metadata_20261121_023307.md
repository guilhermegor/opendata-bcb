## Decision

Source: the SGS WebService via the Axis GET form. Real capture:
`tests/fixtures/sgs/serie_433_ultimo_valor.xml` (whole response, untouched, sha256
`ba89c3532f903e86506425d0c635369ef9143f8d1533f2ff32f5879f9c2e4244`).
Commit `0a4dd5a` (HTML scraper) is not reused: different shape.

## Limits

- The service exposes name, code, periodicity (letter code, e.g. `M`) and unit. It does **not**
  expose the series start date; the issue's "start date" is not delivered. The last-value date
  is in the payload but is data, not metadata, so it is not returned.
- Periodicity is returned as the source letter code, not translated.
