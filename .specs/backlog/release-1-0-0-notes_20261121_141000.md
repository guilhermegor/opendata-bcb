## opendata-bcb 1.0.0

A partir desta versão a biblioteca segue o versionamento semântico.

### Garantia de API da série 1.x

Ficam estáveis:

- os nomes dos dez leitores: `read_banks`, `read_currency_codes`,
  `read_focus_annual_expectations`, `read_ptax_currencies`, `read_ptax_quotes`,
  `read_ptax_usd_brl`, `read_quote_bulletin_codes`, `read_quote_bulletins`, `read_sgs_metadata`
  e `read_sgs_series`, e o `__version__`;
- os nomes dos argumentos (e se são só por palavra-chave) de cada leitor; <!-- codespell:ignore -->
- os nomes das colunas devolvidas por cada leitor.

Não é parte da API e pode mudar em qualquer versão: tudo em `opendata_bcb._internal.*`.

Novos leitores, novos argumentos opcionais só por palavra-chave e novas colunas saem em versões <!-- codespell:ignore -->
menores. Remover ou renomear um nome estável, um argumento ou uma coluna só ocorre em uma versão
maior (2.0).

### Mudanças incompatíveis

- `opendata_bcb.main` foi removido: era o exemplo de boilerplate do template. A API pública é
  formada pelos dez leitores `read_*` e por `__version__`.
- Módulos internos sem uso foram removidos de `opendata_bcb._internal` (não eram API), junto com
  a dependência `pure-schema-regimes`.

### Outras mudanças

- Classificador `Development Status :: 5 - Production/Stable`; o pacote traz `py.typed`.
- `SECURITY.md`: a série 1.x recebe correções de segurança, a 0.x não.
