# Work ledger: hash the same artifact bytes the parser reads (#35)

## Why

Every file reader opened the cached artifact twice: once to parse, once to hash. A concurrent
cache refresh between the two reads stamped a `content_hash` of a different file than the one
parsed. Raised by CodeRabbit on #32 and #33.
